# Key Features

## 1. Intelligent Document Processing (RAG)

- **Upload**: PDF, PPTX, DOCX, TXT files
- **Processing**: Automatic chunking, concept extraction, key point identification
- **Vectorization**: NVIDIA embeddings stored in Qdrant for semantic search
- **Retrieval**: Context-aware retrieval during lessons and Q&A

## 2. AI Curriculum Generation

- **Input**: Any topic or uploaded material
- **Output**: Structured learning path with modules, lessons, prerequisites
- **Adaptive**: Adjusts based on student level and learning pace
- **Capstone Projects**: Real-world application at the end of each module

## 3. 9-Phase Interactive Teaching Flow

| Phase | Purpose | Duration |
|-------|---------|----------|
| 1. Intro | Welcome and context setting | 30s |
| 2. Explain | Core concept delivery | 2-3 min |
| 3. Example | Real-world illustration | 1-2 min |
| 4. Question | Diagnostic check | 30s |
| 5. Feedback | Misconception correction | 1-2 min |
| 6. Re-explain | Reinforcement | 1 min |
| 7. Confirm | Understanding verification | 30s |
| 8. Adjust | Difficulty adaptation | Dynamic |
| 9. Next | Progressive learning | Continuous |

## 4. Dynamic Whiteboard

- **Real-time visuals**: Generated during lessons based on content
- **Code demos**: Live coding examples with syntax highlighting
- **Interactive diagrams**: Concept maps and flowcharts
- **Visual type selection**: Choose between diagrams, charts, code, or text

## 5. End-of-Lesson Assessment

- **Progressive difficulty**: Easy → Medium → Hard questions
- **Immediate feedback**: Wrong answers get explanations
- **Score tracking**: Performance metrics over time
- **Weak area identification**: AI detects knowledge gaps

## 6. Revision System

- **Spaced repetition**: Recommended review intervals
- **Flashcards**: Key concept pairs for quick review
- **Weak area focus**: Prioritizes topics with low scores
- **Session tracking**: Monitors revision progress

## 7. Student Analytics Dashboard

- **Performance metrics**: Quiz scores, completion rates
- **Learning patterns**: Time spent, topic preferences
- **Progress visualization**: Charts and trends
- **Personalization insights**: How the AI adapts to the student

## 8. Multilingual Support

- **6+ languages**: English, Hindi, Ukrainian, Spanish, French, German
- **Seamless switching**: Change language mid-lesson
- **Code-switching**: Hinglish and other mixed languages supported
- **Language-aware teaching**: Adjusts examples and analogies

## 9. Avatar Video Generation

- **Free pipeline**: Edge-TTS + FFmpeg (no paid API)
- **Multiple voices**: Male/female, multiple accents
- **Subtitles**: Synchronized text display
- **Customizable**: Different avatars for different subjects

## 10. Persistent Student Memory

- **Profile system**: Stores learning preferences, history
- **Session continuity**: Remembers where you left off
- **Adaptive teaching**: Adjusts based on past performance
- **Progress tracking**: Long-term learning analytics
